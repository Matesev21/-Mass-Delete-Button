# Salesforce – Mass Delete Button for Custom Objects

This project introduced a custom Mass Delete button to two Salesforce modules to significantly speed up the process of removing multiple records at once. It was implemented to enhance user efficiency and reduce time spent on repetitive actions.

## 🎯 Objective

- Add a "Mass Delete" button to the "Order Labels" and "Kitchen Orders" modules.
- Allow users to select and delete multiple records at once.
- Eliminate the need for manual one-by-one record deletion.

## 🛠️ Technologies & Tools

- Salesforce (Apex, Visualforce, JavaScript)
- Custom Buttons & List Views
- DOM manipulation via inline JavaScript

## 💡 Implemented Solution

1. **Custom JavaScript Button**  
   Adapted and integrated a JavaScript snippet into Salesforce to enable multi-record deletion from a list view.

2. **Deployment in Two Modules**  
   The button was successfully deployed in:
   - Order Labels
   - Kitchen Orders

3. **Code Adaptation**  
   - Retrieved and adapted open-source JavaScript code.
   - Ensured compatibility with Salesforce security model (e.g., URL hacks and field access).

## 🧪 Testing & Results

- Button tested in sandbox before deployment.
- Verified that users could select records and delete in bulk without errors.
- Achieved notable time savings for end users performing cleanup tasks.

## 🚀 Outcome

- Reduced record deletion time by 80%+
- Increased system usability for non-technical staff
- Demonstrated initiative by identifying and solving a workflow bottleneck
